MI DINERO — PWA PRIVADA

1. Sube TODOS estos archivos a un hosting HTTPS.
2. Abre la URL en tu Samsung con Chrome.
3. Usa el menú de Chrome > "Instalar aplicación" o "Añadir a pantalla de inicio".
4. Abre la app desde el icono.

Importante:
- Los movimientos se guardan en el almacenamiento local del navegador/dispositivo.
- No hay servidor de datos ni cuenta.
- Exporta periódicamente el archivo JSON desde "Copia de seguridad".
- Si borras los datos del navegador, puedes restaurar desde ese JSON.
- El service worker permite que la app siga funcionando sin conexión después de haberla abierto correctamente online.
